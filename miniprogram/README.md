# 教师教学质量评价系统 — 微信小程序端

本项目是「教师教学质量评价的智能分析系统」的微信小程序版本，基于 **uni-app + Vue 3 + Pinia** 开发，与 PC 端共用同一套 Spring Boot 后端，数据完全同步。

## 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | uni-app + Vue 3 Composition API |
| 状态管理 | Pinia |
| 网络请求 | uni.request（封装） |
| UI 样式 | 原生 rpx，自定义组件 |
| 图表 | uni canvas 原生绘制（雷达图） |
| 后端 | Spring Boot 3.2.3（复用 PC 端） |

## 功能模块（与 PC 端一致）

### 学生端
- ✅ 首页（公告 + 评价概况 + 快捷入口）
- ✅ 评价教师（学期切换、教师列表、12题问卷+前置题+简答题）
- ✅ 评价历史（按分数/时间排序、查看记录详情）
- ✅ 教师反馈（查看教师反思与改进计划，含均分展示）
- ✅ 通知公告（分页列表 + 详情）

### 教师端
- ✅ 首页（欢迎横幅 + 统计卡片 + Canvas 12维雷达图 + 维度得分率 + 评语）
- ✅ 评价查看（分学期、各题明细、学生评语）
- ✅ 教学反思（填写/编辑反思与改进计划，历史记录）
- ✅ 教学改进报告（AI生成：亮点、不足、建议）

### 管理员端
- ✅ 系统概览（统计卡片 + 教师排行 + 评分柱状图）
- ✅ 数据分析（统计/动态权重/聚类/参与度，4个标签页）
- ✅ 用户管理（分页、搜索、角色筛选、增删改、禁用/启用、重置密码）
- ✅ 反馈查看（学期筛选、关键字搜索、按均分排序）
- ✅ 公告管理（增删改、置顶）
- ✅ 学期管理（增删改、设为当前学期）

## 快速开始

### 1. 修改后端地址

> `src/utils/request.js` 第 2 行，改为你的服务器 IP：

```js
const BASE_URL = 'http://你的IP:8080/api'
```

**注意：** 微信小程序只支持 https，本地调试时可在微信开发者工具中勾选  
`详情 → 本地设置 → 不校验合法域名`

### 2. 编译到微信小程序

```bash
# 安装依赖
npm install

# 开发模式（热更新）
npm run dev:mp-weixin

# 生产构建
npm run build:mp-weixin
```

### 3. 导入微信开发者工具

打开**微信开发者工具**，导入 `dist/dev/mp-weixin`（开发时）或 `dist/build/mp-weixin`（生产构建）目录。

### 4. AppID（可选）

在 `src/manifest.json` 的 `mp-weixin.appid` 字段填入你的小程序 AppID。  
本地调试可以不填（使用测试号）。
